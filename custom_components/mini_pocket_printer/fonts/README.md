| ------------ | -------------------------- | ------------------------------ |
| `dotmatrix`  | VT323-Regular.ttf          | matriciel, facon caisse et terminal |
| `receipt`    | CourierPrime-Regular.ttf   | machine a ecrire, chasse fixe  |
| `receipt-bold` | CourierPrime-Bold.ttf    | idem, graisse renforcee        |

ou passez son chemin complet au service.
